\# 01 - PROJECT CONTEXT



\## What is SMZone?

SMZone is an AI-first Social Media Operating System that connects social media, e-commerce, AI, analytics and automation into a single workspace for businesses.



It is NOT a scheduler. Scheduler is a feature.



\## Target

\- SMBs

\- E-commerce brands (Shopify, WooCommerce first)

\- Creators



\## Core Problem

Businesses juggle 5+ tools: Canva, Meta Business Suite, Notion, Analytics, Drive.

SMZone replaces them with one OS.



\## Current Stack

\- Laravel 12, PHP 8.4, Filament v4, Livewire 3.5

\- SQLite dev, Postgres prod

\- Herd, GitHub, VS Code, Windows
