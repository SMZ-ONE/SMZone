# 07 - UI/UX GUIDELINES

## Principle
Filament default theme is enough. No custom design in Phase 1. Speed > Pixel perfect.

## Rules
- Every List page: search + filter by status + filter by platform
- Empty state: Icon + "No X yet" + CTA button "Create first X"
- Actions: View, Edit, Delete grouped. Publish as extra action.
- Forms: 2 columns max, use Section with description.
- Language: English for code and UI for now.

## Content Planner Specific
- Calendar view via Filament widget later
- Table badge colors: draft=gray, scheduled=blue, published=green, failed=red
