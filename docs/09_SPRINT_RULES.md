# 09 - SPRINT RULES

Every task follows this template:

🎯 Hedef: 2 sentences what will be done
💻 Komutlar: max 3 artisan commands
✅ Test: Which URL to open and what to see
💾 Commit: suggested commit message
☁️ Push

Rules:
- No task without Test step.
- One Resource per sprint if possible.
- Max 20 minutes per sprint.
- If stuck >10 min, ask Founder.

Example Sprint:
Hedef: AI Center mock page that shows future features
Komut: php artisan make:filament-page AiCenter --type=custom
Test: /admin/ai-center opens with 3 mock cards
Commit: feat: add ai center mock page
